# SafePaw 🐾 
**Your Ultimate Pet Care & Emergency Companion**

SafePaw is a native iOS application designed to help pet owners handle medical emergencies and manage daily care. Built entirely with SwiftUI, it provides offline access to life-saving first-aid animations and utilizes MapKit to instantly locate the nearest veterinary clinics.

## ✨ Key Features
* **🚑 Emergency First-Aid:** Step-by-step, offline-accessible animations for choking, poisoning, heat stroke, and more.
* **📍 Live Vet Finder:** Integrated with Apple Maps (MapKit) to locate nearby vet clinics and route users immediately.
* **🐕 Comprehensive Care Guide:** Interactive flashcards and guides covering diet, grooming, and breed-specific health risks.
* **🌙 Native Dark Mode Support:** Fully optimized UI that adapts to user system preferences.

## 🛠 Tech Stack & Architecture
* **Framework:** SwiftUI
* **Architecture:** MVVM (Model-View-ViewModel)
* **Native Apple Frameworks:** * `MapKit` & `CoreLocation` (for Vet Finder)
  * `AVKit` (for looping first-aid videos)
  * `Combine` (for reactive data handling)
